# 低原生学习率：固定 M32 的匹配对照

用户要求主干小步微调，新桥保留较大学习率；本轮只改变学习率。
从已完成平台期的 seed3416、3417 独立模态检查点分别重跑无桥和 R&B。

- 主干 `3e-6`，任务头 `1e-5`，桥 `1e-4`。
- stage3，统一 `M=32, S=64, rho=0.125`；全参数训练、BN更新、AdamW、梯度裁剪和平台期规则不变。
- 各种子内部无桥/R&B使用相同原生检查点、样本顺序与优化器初始状态。
- 联合阶段仍按两分支平均macro-F1选择共同检查点；分别报告两分支指标。
- 先等待已有队列结束，再在全局锁内部署，继承该队列最终账目；累计不超过240 GPU分钟，每卡本项目不超过10 GiB。
- 不读取测试数据；不恢复周期提醒。结果只作为经历史筛选的开发集探索性证据。

通用接口另支持按原生节点键指定M和rho，快速实验仍使用标量广播；本轮不启用异构值：

```python
bridge = {
    'nodes': ['cfp_stage3', 'oct_stage3'],
    'M': {'cfp_stage3': 16, 'oct_stage3': 32},
    'rho': {'cfp_stage3': 0.125, 'oct_stage3': 0.0625},
    'S': 64,
    'mode': 'radon',
}
```

M和rho可分别为标量或完整节点映射，映射不依赖字典插入顺序，缺失或多余键报错。
固定压缩宽度只能固定中间mixer容量，不能保证压缩/恢复层总参数量相同。

CPU验收：实际AdamW步长和旧学习率默认兼容；标量/等值映射逐位一致；异构M/rho的MHD原Node ID、前后向和跨分支梯度；原六组检查点初始预测一致；调度预算和防覆盖检查。
