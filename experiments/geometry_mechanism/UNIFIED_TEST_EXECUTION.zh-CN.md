# 统一test执行衔接

本文件实现已批准的统一test协议，不新增训练或根据test选择配置。777个模型视图的开发集严格重放已经全部通过；来源审计限定当前统一队列及模型祖先，保留早期LOOK交叉使用记录，不扩大“独立test”的含义。

执行顺序：核对现有来源和缓存SHA → 编译既有比较及别名映射 → 提交代码和不含参与者数据的清单摘要 → 6个开发集评价入口/诊断预检 → 自动锁定授权 → 777个完整模型评价、24个四状态宿主诊断、54个64状态配对诊断 → 统一统计与报告。预检含独立父模型、多桥、MMTM和注意力宿主、SVD和QR配对诊断；所有模型还须满足此前777项重放。任何预检失败阻止test，不跳过或更换科学配置。

比较编译仅调用既有方法定义，或逐字转录已登记的稀疏权重。模型通过源引用和检查点SHA关联，不能仅按相同预测合并。相同模型视图/分支/带符号权重的重复假设去重，并保留全部原比较族别名。原等计算条件不可行的比较明确记为不可估计，仍保留记录。原探索压缩对比继续作为次要比较。

test中只读取开发集选定检查点，严格MHD加载、eval/no_grad、batch16。没有优化器、基拟合、校准或阈值优化。宿主四开关结果核对原生单独拓扑；配对诊断复用已验证的跨来源块干预代码，只移动完整参与者双眼，20组独立、标签无关、无自配对置换，两个方向使用置换及逆。

独立入口要求锁定清单、来源和预检证据、提交SHA；历史训练摘要保持原样。双/单/多卡由已有任意GPU集合接口控制，各卡本项目合计≤10GiB；不触碰LOOK。进程中断保留attempt，已验收结果按SHA复用。确定性错误不无条件重试；新版本保留旧输出并重新验收，不改变模型选择。数据和证据文件不得因恢复而覆盖。

自动统计输出每个模型及原研究引用的development/test对照、CFP/OCT/分支均值/固定概率融合及辅助指标。10000次参与者bootstrap在每个集合内跨全部模型共享索引；development和test独立抽样。原比较族及全局max-|t|同时区间，零方差不除零，不可估计项保留。图按锁定顺序完整展示，不能按test显著性选择面板。

模型预测、缓存特征、置换及参与者清单只留授权工作站。report目录仅存安全聚合材料，后续监控自动同步GitHub和本地并完成视觉验收；完成/失败/需处理时才通知，最终交付后暂停监控。
