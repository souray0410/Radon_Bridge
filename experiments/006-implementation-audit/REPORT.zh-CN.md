# 005复核：实现、训练独立性与基线强度

诊断对象为005的真实last检查点，原训练源码88882f4；ws复核时源码d2dadf7。
仅作只读检查点诊断，不进行新的性能训练，不打开测试集。

## 已确认的问题

1. 说明书Master Stage7要求strong baseline，但尚未建立稳定、足够强的无通信基线。
   005仅256训练参与者，选择了ImageNet ResNet18/膨胀3D主干，未验证其对当前任务足够。
2. 暖启动只解冻stage4；续训同时解冻stage3+4并重置AdamW状态。
   这不是单一训练条件的连续延长。桥接各臂之间条件一致，但无法把共同退步归因于桥接。
3. 两个头的梯度一起做global norm clipping。无特征通信不等于优化独立：
   g_c <- g_c * min(1, 5/sqrt(||g_c||²+||g_o||²))。
   OCT梯度会改变CFP更新倍率。真实检查点第一诊断小批量：CFP梯度范数0.8254，
   OCT62.9918；共同裁剪倍率0.07937。此时CFP本来无需裁剪，却被显著压低。
   诊断使用batch2，不把这个倍率当成历史所有batch4更新的统计。
4. 暖启动单任务CE，续训两任务CE取mean，单任务梯度额外变成1/2。
   Adam对恒定尺度有一定抵消，但epsilon、时间变化的共同裁剪和重置动量不能忽略。
5. 先前只有投影和合成图验收，缺少真实训练条件下的更新独立性与通信幅度诊断。
   这些验收不能支持“已经全面验证正确、配置足够好”的说法。

## 实现本身核对结果

- 完整独立输出头和CE；桥接位于中间stage，之后各自继续主干和任务头。
- Householder构造几何投影A，投影后压缩、线性跨参加者混合、独立展开、A转置回投影、直接残差。
- S采用每参加者完整支持映射至共同采样长度；这是规范化feature坐标，未声称物理配准。
- 对三种真实检查点各做两个连续真实小批量MHD/原生前后向检查；在与训练相同的
  确定性设置下最大梯度误差均为0。未发现MHD路由或反向传播不一致。
- 初版诊断未设置训练使用的确定性选项，严格逐元素容差曾失败；恢复相同设置后一致。
  不把诊断自身的非确定性误差包装成训练框架bug。
- 打乱另一分支输入确实影响有桥接网络的当前分支输出；无桥接影响精确为0。
  桥接没有断路，但两方向的影响不对称。4人批次干预只是诊断，不能量化泛化收益。

## 修正范围

新增optimization.py：分支主干/头各自裁剪，通信参数单独裁剪；新训练显式使用各任务CE之和，
使没有桥接时每条分支的原始梯度尺度与独立单任务相同。任务权重仍相等。
训练协议必须显式提供warmup_adapt_stages、adapt_stages、loss_reduction=sum、clip_policy=per_task。
旧005协议不可静默套用新训练器；重现旧实验应使用时间戳归档源码。

新增check_optimization.py：故意扩大OCT头的梯度，比较独立CFP与并置双任务CFP的两步AdamW
实际参数更新，要求逐元素相等。这项验收结果在运行后补充。

下一轮的先决条件是稳定无桥接基线；不要立即重复同一套性能五臂或把更大H当成默认答案。
阶段性检查顺序：修复训练独立性 → 固定解冻策略与优化器状态口径 → 建立基线的训练/验证曲线
→ 核实任务互补性与通信幅度 → 再做同条件桥接对照和新种子复核。
