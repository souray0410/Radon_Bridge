# R&B 当前实现与结果解释（2026-09-04）

本记录核对当前源代码与既有真实实验，不启动新训练。模型采用真实 ResNet18，
tiny 网络仅用于数值测试。当前联合 R&B 模型共有 45,759,874 个参数，桥接模块
1,421,312 个；暖启动后训练桥接及 2,050 参数分类头，其余主干冻结。

| 配置 | CFP | OCT |
|---|---|---|
| 输入，每眼 | 3×224×224（另测96） | 1×32×96×96 |
| 主干初始化 | ImageNet ResNet18 | 同一2D权重沿深度平均膨胀的3D ResNet18 |
| 桥接位置 | stage3 后、stage4 前 | stage3 后、stage4 前 |
| 桥接特征 | 256×14×14（96输入为6×6） | 256×8×6×6 |
| 角度网格 | M1=8 | M1=4, M2=4 |
| 名义方向数 K | 8 | 16（极点重复，实际13种法向） |
| 投影长度 S | 16 | 16 |
| 展平通道 P=C×K | 2048 | 4096 |
| Handoff H，比例1/32 | 64 | 128 |
| 离散投影矩阵 | 128×196 | 256×288 |

所有角度在 [0,π) 均匀取样，并使用角度积分权重。OCT 4×4 网格在极点
重复四次，已计入权重，并非16个各异方向。原生特征坐标按网格归一化，
没有使用 OCT 物理体素间距，也未进行 CFP/OCT 精确几何配准。

对于每个分支 i：先以 Householder 定义方向，多线性插值后作超平面积分，
得到固定离散算子 R_i。投影结果将特征通道与方向合并，经过可学习、无偏置
1×1 Conv1d 压缩为 H_i×S。两分支拼成192×16，使用一个192→192、核宽3的
无偏置线性 Conv1d Mixer；再分别1×1扩展、通过 R_i 的精确离散转置返回，
直接残差相加。无学习门、额外非线性或 gamma，Mixer 初始为零。

表达式：U_i=C_i R_i F_i；[V_c,V_o]=K*[U_c,U_o]；
F_i'=F_i+R_i^* E_i V_i。这里 R_i^* 是伴随，不是逆变换。
随后各分支经过 stage4、空间平均和双眼平均，拼接1024维，线性二分类。
每一步作为 MHD 节点/边表达，前后向均走 MHD。桥接对输入特征是线性的，
并不代表整个残差主干网络是线性的。

训练：256训练/128验证参与者，病历定义的参与者级青光眼标签；每批4人、
双眼。暖启动10轮仅训练stage4与分类头；随后10轮训练桥接与分类头，BN统计
冻结。AdamW lr=1e-4、weight_decay=0.01、梯度裁剪5；两个联合模型种子。

简化的限制是实质性的：单尺度、较少方向、短投影、强压缩、冻结主干和小队列。
因此阴性结果不能否定完整 R&B。更准确地说，当前实现受约束很强，并非模型
总参数很少。以前25% Handoff约1756万桥接参数也没有改善，但那次stage4训练
策略不同，不是单因素宽度消融。尚未做普通可学习投影、cross-attention或
RETFound/OCT专用预训练的对照，不能声称优于这些方法。

下一步需分开检验角度密度、S、H、插入层次和末阶段适配，配套参数量与计算量
对照，并加强训练样本与基线。不要同时增大所有配置后把变化归因于某一个因素。
不能把统一张量形状当成跨模态语义/物理坐标已经对齐。

固定末轮、相同验证参与者的完整比较见003报告，独立训练模型的等权融合
见004报告。两种口径应分开：同源暖启动的四臂是机制对照，独立训练后的晚期
融合是实用基线；后者不是严格匹配参数量/训练预算的机制消融。
