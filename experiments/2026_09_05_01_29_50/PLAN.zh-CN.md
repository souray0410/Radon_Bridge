# R&B（Radon Bridge）：固定SVD通道压缩的12项配对实验

这是新增计划及实现，不表示GPU验收或训练已经完成。运行状态以新目录queue_status.json、preflight/status.json和status.json为准。

| 项目 | 设置 |
|---|---|
| backbone LR | 3e-5、6e-5 |
| head / bridge LR | 1e-4 / 1e-4 |
| seed | 3416、3417 |
| rho | 1/16、1/8、1/4 |
| r / 每路h | 16/512、32/1024、64/2048 |
| 几何 | stage3、M32、S64、普通直接反投影 |
| 训练 | 全参数，BN更新，batch16，AdamW WD0.01，分支和桥分别裁剪5 |
| 平台规则 | 至少8轮、6轮无>0.001改善、3轮停滞LR×0.3、60轮保护上限 |

先等待2026_09_04_23_54_10的16项及2026_09_05_00_05_58的16项全部平台结束。学习率/rho矩阵的12项标准桥为一一配对参考，对应4项无桥为基线。以同seed、LR、父检查点和完整配置匹配；共同最佳检查点沿用当前两任务平均macro-F1选择规则，分支各自报告。

用每个种子的独立检查点提取仅训练集native stage3特征：每个空间位置的C维向量累积FF^T，除向量数N后在CPU float64特征分解。完整Q按特征值降序排列，列最大绝对分量规范为正。此为非中心化SVD，可保持全线性桥。不同rho取前r列；跨LR复用同一文件。不按累计90%能量改变r，也不按标签选择方向。完整基、二阶矩、谱、版本、数据审计、参与者ID摘要、父权重摘要及文件SHA全部归档。运行时实际float32截断基也独立归档，并进入检查点。

拟合的计算量主要是每个种子一次训练集只前向遍历及通道统计；仅4个256×256矩阵在CPU分解，不保存完整特征库。报告拟合时间与训练成本分开，实测rho1/4完整GPU前向/反向/AdamW更新、跨路梯度及显存。失败不启动正式12项，不擅自缩小batch。

报告两种压缩的CFP、OCT及平均F1、相对匹配无桥增益、固定减可学习差值；参与者级配对bootstrap 10000次，区间条件于已选择开发集检查点，不能消除筛选偏差。不把两种子的样本合并冒充独立参与者。统一图例、rho分数、stage/M/S、颜色；报告参数、选中/停止轮次、GPU耗时/显存以及各宽度保留能量。

这同时改变了两端可学习性和投影结构，不能将差异全部归因于是否训练。原生网络持续训练，最初拟合的能量排序也不保证在后续保持最优。两个种子差异包含预训练特征、拟合基和联合训练随机性的变化。低能量判别信息可能通过与保留方向的关联被部分传递，但不保证保留。仍是探索性开发集证据。
