# R&B（Radon Bridge）：补齐M32机制对照

在当前16项学习率/ρ实验完成后，补充高斯随机投影、空间打乱Radon、仅自身处理、普通池化通信。每种对照均使用backbone 3e-5/6e-5与seed3416/3417，共16项新增实验。

Radon类统一stage3、M=32、S=64、ρ=1/8，head/bridge LR均1e-4。直接复用前一队列对应seed/LR的无桥与标准R&B，不重复训练基线。核对父检查点、初始原生权重、收敛状态与摘要SHA。

池化通信不使用M/S，其h=Cρ，与Radon类h=CMρ不同，不将其解释为严格容量匹配对照。仅自身处理采用对角块mixer，保留自身路径、去掉跨来源通信。

不修改正在运行的远端源码；新配置排队待原队列释放锁后部署。沿用无时长预算、每卡10 GiB、batch16、全参数训练与预设平台期规则。ρ=1/2仍排除。最终统一汇总32项实验，旧M16机制结果仅作历史参考。
