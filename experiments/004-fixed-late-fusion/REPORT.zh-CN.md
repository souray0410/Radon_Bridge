# 实验 004：无需再训练的固定融合

> **状态更正（2026-09-04）：** 其中共享头实验不符合用户要求的“独立预测器 + 中间特征桥接”；原结果仅保留作历史探索，不构成该方案的有效性验证。单模态/晚期平均也未按 macro-F1 选优。详见说明书审计。


使用实验 003 的 seed 3407 固定末轮预测，等权概率平均，不拟合权重、不按
验证集调整阈值；仅 CPU 计算，无新增 GPU 训练。执行提交为 `run/004-source`
（0cdc1ad6e3f66a22e578879c04977079fc4d49b4）。全部 128 人标签与顺序核对一致。

224 等权概率融合相对 CFP、OCT 的 AUROC 差值分别为 +0.0325、+0.0391，
相对联合基线 +0.0388，相对 R&B +0.0505。四个探索性 paired bootstrap
95% 区间分别为 [-0.0276,0.0956]、[-0.0333,0.1127]、[-0.0379,0.1130]、
[-0.0139,0.1160]，均跨零；没有证实稳定的总体增益。

这提示模态间可能存在可用互补信息，而本轮联合训练/桥接未充分利用。
下一阶段必须保留独立单模态及等权概率融合作为实践基线，优先改善联合
模型的泛化、减少过拟合，再问 R&B 的几何是否提供额外收益。不能用这个
结果证明 Radon 无效，也不能省略强晚期融合基线来制造方法优势。

限制：同一小验证集反复用于探索；只有一个单模态训练种子；暖启动仍有
验证集选优；未使用独立测试集。该诊断是在实验 003 结果可见后设计的，
不属于预先确认性分析。独立训练后的融合与联合模型参数量不同，因此
这是实用基线，并非参数严格匹配的机制消融。完整指标见 aggregate.json。
