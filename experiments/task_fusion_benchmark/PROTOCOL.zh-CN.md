## 问题和边界

比较相同已训练2D/3D原生网络上的任务级融合系统。所有方法保留CFP/OCT原任务头，新增融合预测；原R&B独立预测器机制证据仍单独报告。本轮不能只凭更换单一输出而声称证明桥本身有效。

## 固定矩阵：9配置 × 2学习率 × 3种子 = 54

| 配置 | stage3通信 | stage4融合读出 |
|---|---|---|
| Concat + MLP | 无 | 两路平均汇聚、拼接、MLP |
| Gated attention MIL | 无 | 两路独立门控注意力汇聚、拼接、相同MLP |
| R&B SVD rho=1/16 | 标准Radon M32/S64，r16/h512 | 相同平均汇聚MLP |
| R&B SVD rho=1/8 | 标准Radon M32/S64，r32/h1024 | 相同平均汇聚MLP |
| R&B SVD rho=1/4 | 标准Radon M32/S64，r64/h2048 | 相同平均汇聚MLP |
| MMTM reduction4 | 已验证单stage适配，共享隐层256 | 相同平均汇聚MLP |
| MMTM reduction8 | 已验证单stage适配，共享隐层128 | 相同平均汇聚MLP |

| Cross-attention d256 | 已验证双向4头适配 | 相同平均汇聚MLP |

每个配置完整运行backbone LR=3e-5、6e-5；原任务头、融合头与通信模块均1e-4。每个配置分配相同的两档优化比较；不声称每个方法家族的配置数、参数量或历史搜索预算相等。全部54项报告，不挑弱对照，不按某个种子分别选学习率，不在看到结果后新增搜索。

融合MLP为1024→256→2，ReLU、偏置，无dropout，正常随机初始化。相同种子在所有方法中使用完全相同的MLP初值；独立CPU RNG作用域不改变原生或通信模块初始化与训练随机流。MIL门控权重独立初始化，不按开发结果筛选初始化。

MIL实例是原生stage4的空间特征单元：CFP每眼7×7，OCT每眼4×3×3；两眼合为一个参与者bag。两来源分别汇聚，避免因token数量不同而直接偏重其中一路。对每来源token x_j∈R512：

    a_j = softmax_j [w^T(tanh(Vx_j+b_v) ⊙ sigmoid(Ux_j+b_u))]
    z = Σ_j a_j x_j

门控隐层128，两个来源独立参数；拼接两路512维z后使用相同MLP。这是Ilse等的门控attention-MIL在当前CFP/3D OCT特征上的适配，受多模态眼底MIL工作启发。它没有MM-MIL原文的二维B-scan逐片编码、CFP重复裁剪或额外骨干，不能称完整MM-MIL复现；深层特征已丢失的空间细节不会被MIL恢复。也不把注意力权重称为临床解释证明。

## 相同目标、选优及资源规则

L = CE_CFP + CE_OCT + CE_fusion，三项权重固定1；所有方法完全一致。融合预测macro-F1决定共同检查点、平台期与LR调整。各原任务头F1、两头F1平均及固定平均概率晚期融合均为次要指标，不能替代融合预测F1。初始原任务头输出与对应独立父检查点一致；新融合头随机初始化，不能声称其初始输出等于原概率平均。

MHD V4保持两路完整主干/任务头，桥原stage3 Node ID写回，融合读出接stage4，不回写特征。全参数训练、BN正常更新。batch16有效16，AdamW WD0.01；CFP、OCT、通信模块、融合头各自梯度裁剪5。至少8轮、6轮无超过0.001改善判平台，3轮停滞LR×0.3；60轮仅保护上限。OOM、失败、未平台均需处理，不降低batch或放宽条件。

双GPU，每卡本项目合计≤10GiB、allocator9GiB，空闲≥12GiB才派发；不停止LOOK，时长不限但完整记账。运行前9个配置逐项batch16完整前向/反向/三次优化预检，核验融合损失传至双方、BN和所有参数更新。CPU验收MHD与原生autograd、严格旧检查点、原预测、门控公式、参与者bag边界、随机状态、融合选优和维数。

源代码在隔离检出准备，数值通过后同步GitHub。取得项目锁，GPU预检通过才快进生产代码。唯一运行根目录及分段attempt，已完成且SHA验证的结果不重复；中断重试从相同父检查点重新开始该未完成项，旧attempt/费用保留。活跃控制器或存活worker禁止重复启动；不把不收敛的负结果作为故障重跑。
