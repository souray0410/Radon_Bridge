## 科学问题

在相同父模型、Stage3、压缩秩和通信结构下，将固定通道基从训练特征未中心化二阶矩方向 `FF^T/N` 改为训练集协方差方向 `FF^T/N - μμ^T`，观察桥的表现变化。

中心化只改变 **Q 的拟合方向**。运行时仍为 `Q^T X` 与 `Q delta`，不做输入均值减法或解码均值加法，因此本包不能单独证明“均值造成SVD优势”。

## 锁定范围

- 数据：WS02 青光眼，1264 train / 296 dev；test封存。
- seed：3416。
- 父模型：与已接受 core 的 CFP/OCT 父模型严格同SHA身份；归档路径允许变化但权重SHA不得变化。
- 输入：CFP 224×224；OCT 32×96×96。
- Stage3，r=32，M=32，S=64，k=3，rho=.125，G=1。
- 真实 batch16、原优化器/学习率、FP32与原TF32策略、min8/max60/patience6/min_delta=.001、原初始化和选模规则均不变。
- 旧未中心化 `svd` / `linear` 两项严格复用；只新增 `centered_radon` 和 `centered_linear_resample`。
- 不执行G64/无压缩预算匹配，不新增种子、骨干或比较。
