## 问题与配置

可学习的低秩线性通信能否保留Radon几何收益？完整投影特征先经过全局A，再经过卷积K，最后经B返回：`Wτ = B Kτ A`。无激活、无BN、无偏置；A/B随机初始化，K零初始化。三个R是同一方法的容量设置，不是三种结构。旧按来源独立投影的learned_projected也不是这套全局分解。

青光眼：1264 train / 296 dev（148阳性）；ResNet18二维CFP与三维OCT独立父模型；双眼CFP224×224、OCT32×96×96；Stage3、M32/S64/k3、batch16。AdamW：骨干6e-5、头/桥1e-4、WD0.01，FP32、历史cuDNN TF32开启；至少8轮、最多60轮保护、patience6、改善门槛0.001；每3轮停滞LR×0.3。全网络训练、BN更新，按dev两分支Macro-F1均值选共同检查点，包括第0轮。

固定SVD是实用参照，不是与每种R等参数的控制；每个R的Radon与普通重采样才是对应几何比较。原协议和原始代码保持历史身份：[原协议](https://github.com/souray0410/Radon_Bridge/blob/91beacfdbc3173993dbe84e11a824633b98b28c4/docs/factorized_ws_20260914.zh-CN.md)。

## 匹配差值与反例

Radon减同R普通通信；10,000次共同参与者配对bootstrap，原统计族为3个R×CFP/OCT/分支均值，共9项。以下展示分支均值，全部9项保存在current.json。

|R|差值pp|普通95%区间pp|九项同时95%区间pp|
|---|---:|---|---|
|256|+0.9038|[-0.9993, +2.7742]|[-1.7204, +3.5279]|
|512|+1.6034|[+0.0151, +3.2149]|[-0.6029, +3.8097]|
|1024|+0.8141|[-1.6733, +3.3263]|[-2.6696, +4.2979]|

**结论边界：**分解Radon均值略高于各自普通通信，但三个同时区间均跨零；R256的OCT分支差值约−0.21pp，不能用平均值隐藏分支受损。固定SVD的平均F1更高，但容量/参数化不同，不能直接证明SVD压缩本身更优。R变大收益不单调。均为历史探索dev，模型由同一dev选出，区间未消除选模偏差，也不代表所有随机种子的训练不确定性。
