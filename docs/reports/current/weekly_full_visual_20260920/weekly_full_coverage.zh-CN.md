## 4. 眼科输入先讲清楚
CFP是眼底照片，OCT是断层/体层；两个项目处理的问题不同
- LOOK：缺少一种输入时，能否修正内部数字，让结果更像完整输入
- R&B：两种输入都在时，能否让两条支路交换信息，提高判断
- 本周多数结果仍是开发集、单种子或单配置，不是测试集结论

## 5. 证据规则：先公平，再谈提升
所有结果都按同父模型、同数据划分、同开发集选择来解释
- Macro-F1提升不等于概率质量改善
- 同时区间跨零时，不能宣称稳定优越
- test全程封存；开发集既选路径又报指标，所以结论有界

## 6. LOOK主流程图
缺输入 → 拟合补偿 → 逐层搜索 → 配对统计
流程：原模型训练完成 → 缺OCT/缺CFP → PCA或残差拟合 → best/positive tree → 10k配对区间

## 7. 为什么必须讲positive tree
只选当前最好位置会漏掉“第一步小、后面更好”的路径
- best-forward：每次只接着当前最佳位置继续
- positive-forward tree：保留所有有正收益的分支，再沿各自下游继续
- 关键约束：每条分支必须用它自己的修正特征，不能套别的缓存

## 9. 拟合方法：PCA方向 vs 自由低秩残差

- 核心问题：换拟合家族本身是否改变结果，而不是换数据/换宿主
