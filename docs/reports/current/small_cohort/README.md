## 阅读图表前：缩写和参数

CFP（Color Fundus Photography）是彩色眼底照片分支；OCT（Optical Coherence Tomography）是光学相干断层扫描分支。SVD指奇异值分解，本项目用训练特征确定固定通道方向；QR是随机矩阵正交分解，方向不按信息重要性排序。

Stage3指第3个残差阶段后的通信位置；r=32指每个分支压缩后保留32个通道方向；M=32指投影方向数；S=64指每方向采样格点数；k=3指通信一维卷积核宽。分支均值Macro-F1是两分支指标平均，不是融合预测准确率。
