# WS02：已有MMTM方法加桥的单种子阶段

本包回答老师的“已有方法A是否能被桥进一步改善”，不是继续增加近似骨干。使用原1264训练/296开发青光眼队列、3416、CFP224×224/OCT32×96×96、Stage3；test封存。

三臂：同一已验收MMTM适配模型继续训练／同宿主加并行SVD-Radon残差／同宿主加并行普通通信残差。全部重新建立同配方优化器，真实batch16，min8/max60/patience6/min_delta0.001，保留初始状态参加选模。新增参数不同，是方法差异，不能叫等参数消融。第二阶段全部重新执行，第一阶段分数不能冒充继续训练对照。

第一阶段MMTM最佳轮为0；这是身份初始化的本项目适配，不是作者完整系统。沿用原SVD基的前提是全部原生父权重和Stage3输入状态逐项一致；登记时校验。新桥零初始化须重放相同宿主预测。若宿主未来选中非零更新状态，不能自动沿用本包SVD基。

已有接受文件由单独迁移命令转成完整宿主manifest与模型状态；新加载器核对配置、父模型、种子、所有文件SHA、并行拓扑。每臂完整GPU前后向、全dev、节点写回及下一更新恢复预检通过再训练。原队列/锁/停止规则不变。比较族为Radon−继续、普通−继续、Radon−普通，完成后10k参与者配对普通/三项同时区间；单种子且开发集选模，只给探索结论。
